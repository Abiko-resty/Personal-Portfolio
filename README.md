## About

This repository contains the source code for my personal portfolio website. It highlights my work, experience, and contact details, and can be easily customized and deployed.


## Features

- Home / Hero section with a short introduction
- Projects gallery with links and descriptions
- Skills / Tech stack section
- Contact form or contact links (email, social)
- Responsive layout (mobile-first)
- Light/Dark theme toggle (optional)
- Easy deployment (GitHub Pages, Vercel, Netlify, etc.)

## Built with

- HTML5, CSS3
- Bootstrap


## Deployment
GitHub Pages
- For static sites: push the `build` or `dist` folder to `gh-pages` branch or use `actions` to deploy automatically.


Tips:
- Keep project cards concise: title, one-line description, tech tags, link to repo/live demo.
